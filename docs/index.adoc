[#overview]
[preface]
== A chat that reaches a computer

Envelop is a web chat whose other end is a real 32-bit computer, Tomato. A person sends a message or a small compute job from the browser. A backend holds it until a nearby phone or computer can carry it over Bluetooth to Tomato. Tomato runs the job and writes an answer back.

++++

[#quick-start]
=== Quick start

Open the https://tmarhguy.github.io/envelop/chat/[web chat] and send a
message to Tomato. Messages wait safely in the backend queue when the
physical bridge is offline. To play with the computer itself, visit
https://tomato.tmarhguy.com/[Tomato OS].

[#documentation-conventions]
=== Conventions

* `monospace` identifies commands, paths, and code identifiers.
* Paths are relative to the repository root unless stated otherwise.
* Unmeasured results are marked `TBD (unmeasured)`.
* When prose and implementation disagree, the
  https://github.com/tmarhguy/envelop/blob/main/docs/documentation-policy.md[documentation
  policy] decides which source wins; dated files under `log/` are history,
  never current architecture.
