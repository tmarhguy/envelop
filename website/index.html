00 / WHERE IT STARTED

Tomato first.
Then the world.

Tomato is a 32-bit computer built from scratch in a dorm — chips, boards, its own OS. The first goal was simple: paint a screen, then text a phone. That messenger is Envelop — named for the envelopes that carried word across distance — and its first line was for home: Hello, Hello Ghanafo!

In the app, you ↔ Tomato is a real conversation: you send from your phone or computer; Tomato is the hardware contact with the blue check. When a nearby Envelop bridge is online, your message lands on Tomato’s screen.

02 / A SIMPLE CONNECTION

You ↔ Tomato.
Same network.

You are a person on Envelop — pick a name, find contacts, send text. Tomato is not another user account; it is the dorm-built computer itself, pinned at the top with a verified badge so you always know who you are talking to.

When you text Tomato, the message waits in Envelop until a nearby phone or Mac holds a Bluetooth bridge, then it appears on Tomato’s screen. Offline bridge? The note waits.

03 / FIRST STEPS

From download to hello.

Unsigned builds · download · enter your name.

01 Install on Mac

Download the Mac archive, unzip it, move Envelop.app into Applications. The build is unsigned, so macOS will object on first launch: right-click (Control-click) Envelop.app, choose Open, then Open again. If it still refuses, run xattr -cr /Applications/Envelop.app in Terminal and try again.

Open Envelop and enter your name. Bluetooth is only needed when connecting Tomato.

02 Install on iPhone or iPad

Prefer AltStore or SideStore: download the IPA (or Apple source if no IPA is listed), open it in AltStore/SideStore with your free Apple ID, then Install. Re-sign about every 7 days on a free Apple ID.

With a Mac and a cable: open apple/Envelop.xcodeproj from the source zip in Xcode, select your free Apple ID team and your device, then Run.

After install, open Envelop and enter your name.

Download Apple source
03 Install on Android

Download the APK, open it, and allow installs from your browser or file manager when asked. Open Envelop and enter your name.

04 Install on Windows

Download the Windows archive, extract the folder, run Envelop.exe. If SmartScreen warns about an unknown publisher: More info → Run anyway. The published build is self-contained — no separate .NET install.

Open Envelop and enter your name.

05 Meet Tomato

In Envelop, Tomato is a contact — the computer, not a person with a phone. When you send to Tomato, the text is meant for that machine’s screen. A nearby Apple client holds a Bluetooth lease so messages can cross from the Internet to the hardware.

Only one device holds the Bluetooth connection at a time. Local BLE chat firmware stays on Tomato; the Internet path needs firmware that speaks Envelop’s binary protocol.

06 The test network

These downloads connect to the Envelop test network automatically. You only enter a name.

If you build from source yourself, bake the publishable network URL and key into the client. Never put a service-role key in any Envelop app.
