TOMATO REPLIES · LABELED TARGET

12 / 0x0000000C · Virtual Tomato

Verified on the actual CPU RTL simulator running the OS. Hardware answers are labeled Hardware Tomato.

Hardware first. A clear fallback.

The Mac preview tries its connected Tomato first for every new job. If hardware is unavailable, unsupported, or doesn’t reply in time, it asks Use Virtual Tomato / Cancel.

Cancel runs nothing virtually. A new job tries hardware again. Every result names its target. Completed virtual jobs are never queued to run later on hardware. A timeout means no confirmed result — not proof the hardware never ran.

Try the right experience.

1 · Web chat (live now): talk to people or hardware Tomato. Offline? Run it now in in-browser Virtual Tomato — no install.

2 · Virtual Tomato (play now): boot the OS, open Envelop inside, connect the demo phone. Browser emulation with simulated peripherals.

3 · Local compute preview (tested): Mac app + CPU RTL service on your Mac. Local setup and supported operations →

Current compute jobs: 32-bit arithmetic and bitwise ops (ADD / SUB / AND / OR / XOR / MASKADD / XORAND + private LOAD / STORE), eight private registers R0–R7, 256 private memory words, up to 32 straight-line instructions with final RETURN. Raw LUT config, multiplication / division, loops and arbitrary OS memory access are unsupported. Greeting / help / unknown chat get short bounded replies.

02 / A SIMPLE CONNECTION

You ↔ Tomato.
Same network.

You are whoever is online: pick a name and the green dots show who else is here. People come and go, and the list keeps up. Tomato is not another user account; it is the dorm-built computer itself, pinned at the top with a verified badge so you always know who you are talking to.

When you text Tomato, the message waits until a nearby Mac or Android bridge forwards it over Bluetooth. If the bridge is offline, the note waits until it returns. Leave Envelop, and your name and chats are deleted for good.

Going quiet? Close the tab and you simply drop off the list. Leave Envelop in the sidebar deletes your name and chats for good.

02 Meet Tomato

In Envelop, Tomato is a contact — the computer, not a person with a phone. When you send to Tomato, the text is meant for that machine’s screen. A nearby Mac or Android phone holds a Bluetooth lease so messages can cross from the Internet to the hardware.

Only one device holds the Bluetooth connection at a time. Local BLE chat firmware stays on Tomato; the Internet path needs firmware that speaks Envelop’s binary protocol.
