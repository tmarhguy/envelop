02 / A SIMPLE CONNECTION

Internet for everyone.
A bridge for Tomato.

People message each other over the Internet. Open Envelop, choose a name, find someone, and say hello.

Tomato joins through a nearby Envelop bridge using Bluetooth. You can message Tomato from anywhere. When its bridge is offline, messages wait until it returns.

Your device→Envelop→Bridge→Tomato

03 / FIRST STEPS

From download to hello.

These are development builds.
Store releases are not available yet.

01 Install on Mac

No App Store involved. Download the Mac archive above, unzip it, then move Envelop.app into Applications. This early-access build is unsigned, so macOS will object on first launch: right-click (Control-click) Envelop.app, choose Open, then Open again. If it still refuses, run xattr -cr /Applications/Envelop.app in Terminal and try again.

Set the network's Supabase project URL and public key in Envelop, then choose your name. Bluetooth is only needed when connecting Tomato.

02 Install on iPhone or iPad

No App Store involved, so Apple makes you work a little. Easiest path with a Mac and a cable: download the Apple source project, open apple/Envelop.xcodeproj in Xcode, select your (free) Apple ID team and your connected iPhone or iPad, then Run. Free signing refreshes every 7 days — just re-run from Xcode.

No Mac? Use AltStore or SideStore on the device itself: they install the same source build with your free Apple ID over Wi-Fi. There is no App Store or TestFlight link, by design.

Download Apple source
03 Install on Android

No Play Store involved. Download the APK, open it, and allow installs from your browser or file manager when asked — a one-time toggle. Then open Envelop and enter the same network URL and public key as your other devices.

The first signed APK ships with the next Android build; until then the card above says so honestly.

04 Install on Windows

No Microsoft Store involved. Download the Windows archive, extract the whole folder, then run Envelop.exe. Windows SmartScreen will warn about an unknown publisher: choose More info, then Run anyway. The published build is self-contained, so no .NET install is needed.

Enter your network URL and public key when Envelop opens. The first signed archive ships with the next Windows build.

05 Connect Tomato

Envelop is the first third-party app on Tomato — a 32-bit computer designed and built from scratch in a dorm room. Its original line-based chat firmware cannot join the Internet bridge; Tomato needs firmware that understands Envelop's binary protocol.

The nearby Apple client verifies Tomato before requesting a bridge lease. Your network administrator must authorize that bridge account. Only one device can hold the Bluetooth connection.

Follow the hardware: Tomato on GitHub · Read the paper. Hardware integration and physical acceptance testing are tracked with the firmware source. Do not flash an image intended for a different board.

06 Which Envelop network?

All devices must connect to the same Supabase project. This repository does not yet include a hosted public Envelop network. Its operator supplies a project URL and public publishable key.

The public project key is configuration, not a password. Never put a Supabase service-role key in any Envelop app. Your anonymous identity stays on your device; removing its saved app data may lose access to that identity.
