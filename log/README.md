# Engineering log

Files in this directory are dated historical records of ideas, decisions, and
experiments at the time they were written. They are intentionally preserved,
including superseded platform, presence, architecture, naming, and availability
claims.

They are **noncanonical**. For current facts use
[`docs/status.md`](../docs/status.md), and resolve conflicts using
[`docs/documentation-policy.md`](../docs/documentation-policy.md). An old log or
screenshot is not evidence that a feature is currently supported, deployed, or
online.
